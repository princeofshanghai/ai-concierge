# Project Docs

This folder contains the project planning, product, and conversation design documents for the AI concierge prototype.

- [project-overview.md](project-overview.md): high-level product concept and framing
- [mvp-spec.md](mvp-spec.md): MVP scope and prototype boundaries
- [persona.md](persona.md): default user persona for the walkthrough
- [conversation-strategy.md](conversation-strategy.md): principles for how the assistant should behave
- [conversation-blueprint.md](conversation-blueprint.md): concrete MVP conversation flow
- [routing-outcomes-worksheet.md](routing-outcomes-worksheet.md): working worksheet for the five hidden routing outcomes
- [ae-matched-booking-ui-checklist.md](ae-matched-booking-ui-checklist.md): UI review checklist for the matched AE booking flow
- [implementation-plan.md](implementation-plan.md): execution plan for building the prototype
- [phase-1-flow-notes.md](phase-1-flow-notes.md): notes and thinking for the first phase flow
- [prototype-shell-ui.md](prototype-shell-ui.md): principles for internal prototype controls and scenario switching
- [ai-concierge-typography.md](ai-concierge-typography.md): scoped typography system for the AI concierge panel
- [stakeholder-notes-talk-track.md](stakeholder-notes-talk-track.md): supporting stakeholder communication notes

`AGENTS.md`, `README.md`, and `CLAUDE.md` stay at the repo root because they act more like repo-level instructions and entry points than project reference docs.
